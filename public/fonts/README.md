# Public font sources

## LXGW WenKai title subset

- Typeface: LXGW WenKai / 霞鹜文楷
- Upstream: https://github.com/lxgw/LxgwWenKai
- Webfont packaging source: https://github.com/chawyehsu/lxgw-wenkai-webfont
- Package version: `lxgw-wenkai-webfont@1.1.0`
- Weight: 700
- License: SIL Open Font License 1.1
- License file: `LXGW-WenKai-OFL.txt`
- Added: 2026-07-31

The four WOFF2 files are only the upstream subsets needed by the current homepage title. They are self-hosted so local-network devices render the same display face without a remote font request. If the title copy changes, audit its Unicode coverage before relying on this subset.
