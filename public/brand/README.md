# Catnip 品牌资源约定

Neil Bauman 已于 2026-07-31 提供正式 Catnip 图形。网页品牌入口与浏览器标签页图标统一引用 `logo.png`，不得以字母、emoji、网络猫图或重新生成的近似图形替代。

当前与未来文件约定：

- `logo.png`：当前正式网页 Logo 与 favicon，原始文件为 1078 × 1080 RGBA PNG。
- `logo.svg`：未来如团队提供矢量版，用作默认浅色背景 Logo。
- `logo-dark.svg`：深色背景 Logo。
- `mascot.png`：正式吉祥物透明位图。
- `og-image.png`：默认社交分享图。

当前图片由 Neil Bauman 在项目对话中直接提供，作为本项目正式品牌资产使用。替换时应由 Neil Bauman 提供新版本，并核对授权、尺寸、可访问性文本、深浅色适配和社交平台裁切；应用品牌组件应引用稳定路径，避免把图形细节写死在页面中。
