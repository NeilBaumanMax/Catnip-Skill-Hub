# Neil’s Skill Hub 品牌资源约定

Neil Bauman 于 2026-09-11 明确将公开站名称更新为 `Neil’s Skill Hub`，并提供戴圆框眼镜的白兔头像作为新网站图标。网页品牌入口与浏览器标签页图标统一引用 `neil-rabbit-icon.png`；首页品牌舞台使用参考“找灵感”动作生成的无文字透明角色图 `neil-rabbit-inspiration.png`。

当前与未来文件约定：

- `neil-rabbit-icon.png`：当前正式网页 Logo 与 favicon，原始文件为 675 × 675 RGB PNG，由 Neil Bauman 直接提供。
- `neil-rabbit-inspiration.png`：当前首页品牌舞台角色图，1212 × 1298 RGBA PNG；白兔举灯泡跃出书本，无文字、标牌或矩形背景。
- `neil-rabbit-mascot.png`：上一版首页头像式透明角色图，1254 × 1254 RGBA PNG，保留为历史资产，不再用于首页。
- `logo.png`：旧 Catnip 网页 Logo，保留作为历史资产，不再作为当前公共入口或 favicon。
- `logo.svg`：未来如团队提供矢量版，用作默认浅色背景 Logo。
- `logo-dark.svg`：深色背景 Logo。
- `mascot.png`：正式吉祥物透明位图。
- `og-image.png`：默认社交分享图。

当前图标由 Neil Bauman 在项目对话中直接提供，透明角色图由该图标受控延展。替换时应由 Neil Bauman 提供或明确授权新版本，并核对授权、尺寸、可访问性文本、深浅色适配和社交平台裁切；应用品牌组件应引用稳定路径，避免把图形细节写死在页面中。
