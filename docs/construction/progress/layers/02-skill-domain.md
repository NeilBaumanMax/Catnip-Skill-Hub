## 2026-07-28 19:42 CST / Phase 2 / 开工计划

### 当前目标

建立可供公共页面消费、但不依赖 Next.js、数据库或基础设施 SDK 的 Skill 领域模型，并用静态数据生成首页卡片与详情页。

### 计划改动

- 定义 Skill/Skill Pack、单项/原生包/编辑包、发布状态、分类、作者来源、版本、图片和下载权限。
- 支持 Pack 子项、父子关联和子项是否拥有独立页面。
- 建立纯查询函数和十条 Catnip 原创演示种子。
- 首页改用公开领域查询；新增静态详情页、图片集、功能、场景、子项、用法、效果、风险、来源和相关 Skill。
- 下载与安装仅显示 Phase 3 明确占位，不生成命令、不处理 ZIP。

### 验收指标

- 领域层不依赖 React、Next.js、数据库或对象存储 SDK。
- 十条公开种子覆盖五个主分类与三种子类型，至少含一个原生包和一个编辑组合包。
- 每条数据只有一个主分类、至少一张封面且图片总量不超过八张。
- Pack 子项关系和独立页面开关可由类型表达并在详情页展示。
- 首页不再维护重复 Skill 数组；十个 slug 均生成静态详情页。
- lint、typecheck、build、`git diff --check` 与领域边界检查成功。
