## 2026-07-29 00:18 CST / Phase 6 / 开工计划

### 当前目标

在静态公开目录和现有治理字段之上建立可测试的发现服务、可分享筛选 URL、推荐池随机展示和最小匿名事件计数；保持数据库、外部搜索和统计供应商在 Phase 7 之外。

### 计划改动

- 搜索标题、原名、简介、作者、分类和标签，统一裁剪与大小写规范。
- 主分类与自由标签可组合筛选，所有条件来自 GET 查询参数并由服务端校验。
- 默认推荐仅使用已发布、未隐藏且允许进入推荐池的资源；置顶优先，权重影响随机顺序。
- 建立阅读、下载、安装复制、来源跳转事件白名单与进程内计数 Repository。
- 详情页和操作组件只调用事件 API；主页读取计数快照，不直接修改状态。
- 不做用户身份、唯一访客、Cookie 追踪、复杂排名、搜索引擎、数据库或分析 SDK。

### 验收指标

- 中文和英文查询、分类、标签及组合条件返回正确且稳定的公开资源集合。
- 隐藏、未发布、未进入推荐池或非正权重资源不会错误进入默认推荐。
- 随机排序可注入测试源，不修改领域种子；无筛选时随机，有筛选时结果稳定可解释。
- 统计只能对公开 slug 写入四种增量事件，拒绝未知资源/指标；计数仓储返回副本且实例隔离。
- 首页搜索和筛选可用、结果为空可恢复、卡片保持整张可点击且无直接下载按钮。
- npm test、lint、typecheck、build 和 `git diff --check` 全部成功。
