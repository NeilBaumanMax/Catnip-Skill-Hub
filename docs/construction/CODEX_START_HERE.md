# Codex Start Here

本文件帮助新的施工 Agent 快速定位；执行规范以 `AGENTS.md` 和主需求为准。

## 开始前

1. 按 `AGENTS.md` 的顺序读完必读文档。
2. 核验目录、Git 分支、工作区、SSH 身份、origin 和提交身份。
3. 保护所有既有改动，向追加式进度文件写开工计划。
4. 基于当前提交创建并成功 push 新的开发前备份分支。

## 当前交接入口

以 `HANDOFF.md` 的最新记录为当前状态，以对应 `progress/layers/*.md` 为层级证据。不得仅依据聊天记录或代码猜测施工阶段。

## 结束前

执行规定验证，保留失败与复测记录，检查文档漂移，更新四类收尾文档，审阅差异，明确提交并 push。
